# Data Model: Embeddable React Widget

## Widget Configuration

**Purpose**: Admin-managed configuration for one embeddable chatbot widget.

**Fields**:

- `id`: internal persistence identifier.
- `widget_id`: public stable identifier used by host pages.
- `allowed_origins`: list of host origins allowed to embed and use the widget.
- `theme`: selected runtime theme.
- `greeting`: greeting shown in the expanded chat panel.
- `position`: placement such as bottom-right or bottom-left.
- `enabled_tools`: list of tools exposed through the widget experience.
- `enabled`: whether public config and chat are allowed.
- `created_by`: admin user identifier.
- `created_at`: creation timestamp.
- `updated_at`: last update timestamp.

**Relationships**:

- Created and updated by admin users from the auth system.
- Used by public config, iframe, loader snippet, origin policy, and widget chat.
- Create, update, and delete workflows create audit rows through the Phase 6
  audit service.

**Validation rules**:

- `widget_id` is generated by the system and is safe to expose publicly.
- `allowed_origins` must contain explicit origins and must not use wildcard-all
  values for the demo path.
- `enabled_tools` values must be from the backend-supported tool list.
- Disabled widgets do not return public config and do not start chat.
- Services own transactions; repositories do not commit independently.
- Widget config state changes are not complete unless the matching audit row is
  committed in the same service workflow.

## Widget Config Audit Entry

**Purpose**: Audit record for widget configuration changes.

**Fields**:

- `audit_log_id`: audit log identifier.
- `actor_user_id`: admin who caused the change.
- `action`: `widget_config.create`, `widget_config.update`, or
  `widget_config.delete`.
- `target_type`: `widget_config`.
- `target_id`: widget identifier or internal persistence identifier.
- `timestamp`: action timestamp.
- `metadata`: safe bounded change summary.

**Validation rules**:

- Audit metadata must not contain secrets, admin tokens, raw chat text, or full
  config payloads when a bounded diff is enough.
- Widget config create/update/delete workflows fail or roll back if required
  audit persistence fails.

## Widget Script Snippet

**Purpose**: Admin-visible installation snippet for a configured widget.

**Fields**:

- `widget_id`: public widget identifier.
- `script_src`: backend URL for `/widget.js`.
- `snippet`: one script tag with `data-widget-id`.
- `generated_at`: generation timestamp.

**Validation rules**:

- Snippet must use one script tag.
- Snippet does not include secrets, admin tokens, or internal Streamlit URLs.
- Snippet references the same backend API surface used by widget config.

## Public Widget Configuration View

**Purpose**: Limited runtime configuration returned to an approved host.

**Fields**:

- `widget_id`: public widget identifier.
- `theme`: runtime theme.
- `greeting`: greeting text.
- `position`: widget placement.
- `enabled_tools`: public enabled tool list.
- `chat_endpoint`: endpoint for widget chat.
- `asset_base_url`: base URL for widget assets if needed.

**Validation rules**:

- Returned only for enabled widgets and approved origins.
- Excludes creator, admin-only metadata, internal database IDs when not needed,
  auth details, and sensitive backend settings.
- Uses no-store or short-lived cache semantics because configuration may change.

## Origin Decision

**Purpose**: Result of evaluating whether a host may embed or use a widget.

**Fields**:

- `widget_id`: public widget identifier.
- `requested_origin`: origin observed or declared for the host page.
- `allowed`: boolean decision.
- `reason`: stable reason such as `allowed`, `unknown_widget`, `disabled`, or
  `origin_not_allowed`.
- `matched_origin`: matching allowed origin when allowed.

**Validation rules**:

- Decision is made by backend services, not the loader alone.
- Blocked decisions produce clean public errors without revealing admin config
  internals.
- Origin values are safe-normalized before comparison.

## Widget Frame Request

**Purpose**: Request to render the iframe-hosted widget shell.

**Fields**:

- `widget_id`: public widget identifier.
- `parent_origin`: host origin passed by the loader and checked by backend.
- `request_headers`: safe subset used for origin/referrer checks where
  available.

**Validation rules**:

- Invalid, disabled, or blocked widget requests return a safe frame error or
  blocked response.
- Successful frame responses include frame ancestor restrictions from the
  widget configuration.
- Frame route does not expose admin-only fields.

## Widget Chat Session

**Purpose**: Public visitor chat flow scoped to an enabled widget and allowed
origin.

**Fields**:

- `conversation_id`: widget conversation identifier.
- `widget_id`: public widget identifier.
- `origin`: allowed host origin.
- `messages`: transient client-side display messages.
- `stream_state`: idle, connecting, streaming, completed, interrupted, or error.

**Validation rules**:

- Chat starts only after widget config and origin are accepted.
- Chat endpoint reuses backend chat services and does not create separate
  chatbot logic.
- Interrupted streams leave a visible partial or retryable state.

## Widget Message Event

**Purpose**: Stream event rendered by the widget chat panel.

**Fields**:

- `event_type`: message delta, warning, error, or done.
- `sequence`: event order.
- `content`: display content when present.
- `request_id`: backend request identifier when safe.
- `trace_id`: backend trace identifier when safe.

**Validation rules**:

- Events render in order.
- Error content is clean and contains no stack traces or secrets.
- Widget ignores unknown event types safely.

## Resize Message

**Purpose**: Controlled frame-to-host `postMessage` payload.

**Fields**:

- `type`: fixed value `maintainer-copilot:resize`.
- `widget_id`: public widget identifier.
- `height`: requested frame height.
- `width`: requested frame width.

**Validation rules**:

- Host accepts only this message type from the expected frame and origin.
- Width and height are bounded to reasonable values.
- Resize messages never include chat content, tokens, or config secrets.

## Bundle Size Report

**Purpose**: Evidence artifact documenting embed weight.

**Fields**:

- `loader_raw_bytes`: raw `/widget.js` size.
- `loader_gzip_bytes`: gzip `/widget.js` size.
- `bundle_raw_bytes`: raw initial widget bundle size.
- `bundle_gzip_bytes`: gzip initial widget bundle size.
- `standalone_initial_js`: whether the build emitted one standalone initial
  widget JavaScript bundle.
- `extra_initial_assets`: list of extra initial assets when an exception is
  documented.
- `measured_at`: measurement timestamp.
- `build_id`: build or artifact identifier.
- `notes`: explanation if targets are exceeded.

**Validation rules**:

- Report is regenerated after widget build.
- Report is committed or otherwise available to reviewers before completion.
- One standalone initial widget JavaScript bundle is required unless the report
  documents an unavoidable exception, measured size, and impact.
- Any bundle-size target miss is documented with a concrete reason.

## State Transitions

```text
Widget Config Draft -> Created -> Enabled -> Publicly Loadable
Enabled -> Disabled -> Public Config Blocked
Unknown/Disabled/Blocked Widget -> Safe Blocked State

Host Script Loaded -> Loader Reads Widget ID -> Iframe Injected
Iframe Injected -> Config Loading -> Collapsed Bubble
Collapsed Bubble -> Expanded Panel -> Streaming Chat -> Completed
Streaming Chat -> Interrupted -> Retryable Error State

Widget Size Changed -> Resize Message Sent -> Host Frame Size Updated
Unexpected Message Source -> Message Ignored
```
